# Steam Temes guide

In this part, I'll show you how to adapt steam to your main theme. All this can be found here: https://github.com/tkashkin/Adwaita-for-Steam

## Installation

1. Clone or download the repository:
```bash
git clone https://github.com/tkashkin/Adwaita-for-Steam
cd Adwaita-for-Steam
./install.py
```

2. List Options
```bash
./install.py -l
```

3. Install Customizations (Example)
```bash
./install.py -c catppuccin-frappe -e library/hide_whats_new
```
